# 西安星禾云创官网

西安星禾云创网络科技有限公司的 iOS App 研发官网。

- 已有域名：`xhycapps.com`
- 网站类型：无构建步骤的静态网站
- 主页：`index.html`
- 隐私政策：`privacy.html`
- 使用条款：`terms.html`

## 本地预览

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

## 上线前必做

1. 将 `xhycapps.com` 和 `www` 解析到托管服务。
2. 配置 `hello@xhycapps.com` 企业邮箱，或将网站邮箱替换为真实可用地址。
3. 在联系区补充与营业执照一致的办公地址和电话，便于 Apple Developer 组织账号审核核验。
4. 根据实际业务内容审核隐私政策与使用条款。
